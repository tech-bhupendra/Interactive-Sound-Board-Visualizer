# Retro Synth Pad & Audio Visualizer

An interactive, single-file audio synthesizer soundboard and particle wave visualizer built natively with HTML5, CSS3, and JavaScript. 

This project leverages the native Web Audio API to procedurally generate sound waves entirely via code, removing the need for external `.mp3` or `.wav` assets.

## 🚀 Live Demo

You can host this project easily using GitHub Pages. 
To look at it instantly, save `index.html` locally and double-click to open it inside any modern browser.

## ✨ Features

- **Procedural Audio Generation:** Uses `AudioContext` and `OscillatorNode` mathematical waveforms to generate custom real-time sound effects (Laser, Jump, Explosion).
- **Dynamic Wave Visualizer:** Renders hardware-accelerated canvas animations synchronised directly to user interactive inputs.
- **Dual Control Scheme:** Supports responsive pointer/touch tap events along with physical keyboard hotkeys (`1`, `2`, `3`).
- **Zero Dependencies:** Formatted entirely inside a single standalone document layout.
